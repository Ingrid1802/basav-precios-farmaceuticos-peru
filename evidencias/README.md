# evidencias/: Capturas y archivos de evidencia

Capturas y archivos que muestran que cada experimento se ejecutó, ordenados por integrante.

## Convención de nombres

`Nombre_NN_descripcion.png`, por ejemplo `Ingrid_32_eda.png`. El número da el orden dentro de cada experimento. Si hay dos versiones de una misma captura, la segunda termina en `_b`.

## Contenido

| Carpeta | Contenido |
|---|---|
| `ingrid/` (sueltas `Ingrid_01` a `Ingrid_12`) | Solución Big Data general (Spark, volume, carga, EDA, limpieza, tablas, KPI en Gold, gráficos) y dashboard de Power BI |
| `ingrid/` (`Ingrid_20_*`) | Analizador de rendimiento de Power BI (captura y `PowerBIPerformanceData.json`) |
| `ingrid/BigData_Exp1_Volumen_de_datos/` | E-BD-1: datos sintéticos, resultados, gráfico y Query Profile (100k y 1M) |
| `ingrid/BigData_Exp2_Tipo_de_operacion/` | E-BD-2: Medallion, 10 operaciones, resultados y Query Profile |
| `ingrid/BI_Exp1_Indice/` | E-BI-1: tabla de 1M, planes de ejecución, resultados y lecturas lógicas |
| `ingrid/BI_Exp2_Carga_masiva/` | E-BI-2: entorno, procedimiento, corridas, detalle y resumen con medianas |
| `samuel/` | E-BI-3 (`Samuel_BI_*`, incluye la repetición en Developer `Samuel_BI_dev_*`) y E-BD-3 (`Samuel_EXP_*`) |
| `steve/` | E-BI-5 (`Steve_BI_*`) y E-BD-5 (`Steve_EXP_*`) |
| `gonzalo/` | E-BI-4 (`Gonzalo_BI_*`) y E-BD-4 (`Gonzalo_EXP_*`) (pendiente de subir) |

Los números y el análisis están en el informe final, que cita cada captura por su nombre de archivo.
